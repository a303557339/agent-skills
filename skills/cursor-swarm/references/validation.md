# 实际验证记录

日期：2026-11-07。当前验证环境：macOS、Playwright 1.62.1 随附 Chromium。

## 既有兼容性基线

下列兼容性检查已在新版调度器上重新通过；独立商品页条目另注明验证轮次。

- 物理测试 5 项通过：长时间有限值、追赶和工作光标回归、后台恢复时间上限、30/120 Hz 一致性、完全重叠时的避让。
- 演示页浏览器验证通过：多任务并行、原始文字不改写、滚动后全部任务完成、真实表单提交、重播、卸载和重复挂载。
- 接入边界验证通过：动态新增内容、减少动态效果、触屏无光标绘制、原有样式恢复、运行中应用样式更新、键盘聚焦、富文本排除、SVG pathLength、嵌套滚动、缩放文字、错误依赖恢复。测试中无运行时错误。
- 新版独立迁移：代理仅根据 skill 的三模块接入说明，完成中文商品页的 40 个目标。自动达到 20 个并行工人；第一屏完成后独立游走，滚动后重新招募，全部完成后才聚群。施工中键盘操作、完工后点击、390px 尺寸点击均可加入购物车，计数 0→1→2→3。销毁与减少动态效果验证通过，无运行时错误。
- 查看了演示的开场、施工、跟随和移动端截图，并录制实际浏览器预览。此记录不代表 Safari/Firefox 已完成验证，也不代表任意网页无需适配。

## 群体工作与游走升级：已验证

- `tests/choreography-motion.test.mjs`：飞行端点与动态目的地、正负弧线、拖拽不越界、不同采样帧率一致性、非匀速输入、完整字符边界。已通过。
- `tests/choreography.test.mjs`：动态招募与参与公平性、未完成页面期间无提前 flock、空闲团队缩减与独立游走、新区域补充工人、最终重新聚群、数字 `workers` 上限及演示页实际运行。已通过。
- 原有 `motion.test.mjs`、`browser.test.mjs` 和 `integration.test.mjs` 的升级回归已通过；原站与升级版的实际浏览器运动对照已完成，记录见下方。

实测记录：控制场景中 20 个不同光标并行施工；当前区域完成后保留 6 个独立游走者。滚动后重新招募，进入新一轮并行工作。原站采样：触发后 21 个工作、0 个跟随；约 8 秒时剩 6 个游走者和 1 个离场者。第一版的 28 个提前跟随光标团已移除。测试也确认彩色文本工具停靠时，文字裁剪仍持续推进。

最终群体运动保留原有稳定性测试：环绕加入起伏形状、快速追赶个体和更果断的转向。固定目标的确定性采样中，平均速度由约 86 提至 229 CSS px/s，长时间低速停滞缩短；这些数据描述运动参数变化，不代表主观相似度评分。

行为验收重点是“群体工作 → 分散游走 → 新区域继续工作 → 全部完成再集合”。截图、状态计数和测试只提供各自覆盖的证据；最终观感还需要观看移动、停顿、工具切换和队伍转换。

光标外观补充验证：重画短小圆润的无尾箭头、弧形文本光标、圆头十字和分体钢笔，恢复鲜亮的 12 色配色。已用实际 Canvas 绘制函数检查原尺寸和 4× 细节，并在真实演示的施工与跟随状态截图复核；浏览器无运行时错误。

## 复跑

运行时不需要安装依赖。只有浏览器测试使用 Playwright：

```sh
npm install
npx playwright install chromium
npm test
python3 -m http.server 4173 --bind 127.0.0.1 --directory .
# 在另一个终端执行：
npm run test:browser
```

可用 `SWARM_URL` 改变服务器 URL，用 `PLAYWRIGHT_MODULE` 指向已安装的 Playwright 模块入口。测试截图写入 `artifacts/`；若目录不存在先创建。独立商品页试用仅为验证材料，不属于核心运行时。

已知适配范围：普通 HTML DOM、可测量的 SVG path。旋转／3D 变换文本采用整块裁剪退化效果；动态 CSS transform 动画与跨层 portal 需要按具体项目检查。默认排除富文本编辑器和表单输入本体，输入区域的外壳可作为 rect 目标。

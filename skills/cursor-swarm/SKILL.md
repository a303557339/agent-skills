# Cursor Swarm

给现有页面接入完整的光标行为：开场环绕 → 群体分工绘制 → 分散游走待命 → 新区域继续施工 → 全页完工后重新聚群跟随。交付应包含真正运行的动效；本 skill 附带可复制的核心代码，不只是描述效果的提示词。

## 直接使用核心代码

- [assets/cursor-swarm.mjs](assets/cursor-swarm.mjs)：DOM 目标发现、任务调度、文字显现、拉框、SVG 描线、装饰层、生命周期。
- [assets/swarm-motion.mjs](assets/swarm-motion.mjs)：光标群运动；环绕、追赶、邻居对齐、避让与旋转。
- [assets/swarm-choreography.mjs](assets/swarm-choreography.mjs)：有方向差异的飞行、精确拖拽和按完整字符分段的非匀速输入节奏。
- [demo/index.html](demo/index.html)：完整演示，有真实链接、表单和开始／重播／完成控件。

三个 `.mjs` 文件需放在同一目录。它们使用浏览器原生 API，没有框架或 npm 运行时依赖。优先复制并配置已有实现；仅在具体需求确实超出能力时修改核心，避免另写一套看似相似的鼠标拖尾。

## 接入流程

1. 查看目标页面的入口、框架、主要区块、已有动效，以及真实按钮／表单。如果用户另给了参考网站，先观察其运动、触发方式和绘制顺序；本 skill 的默认风格来自 [Swarm](https://califa.github.io/swarm-site/)，不代表其他参考的逐像素复刻。
2. 将三个核心文件复制到项目的静态资源或源码目录，选取页面根节点。按项目生命周期挂载 `createCursorSwarm()`，卸载时调用 `destroy()`。HTML、React、Vue 的接入示例见 [references/integration.md](references/integration.md)。
3. 为关键可见元素标注 `data-swarm`。文字用 `text`，卡片／按钮用 `rect`，有描边的 SVG path 用 `path`，图片或复杂组件用 `reveal`。用 `data-swarm-id` 和 `data-swarm-after` 表达必要的先后关系。现有 DOM 保留，不替换成截图或虚拟画布。
4. 默认保留 `workers: 'auto'`，让任务密度和新区域出现驱动招募；只有明确需要限制并发时才设数字上限。调整 `count`、`radius`、`speed` 和触发方式，先在真实页面确认完整过程，再提炼配置。自动发现可用于首轮接入；正式交付优先明确标注，保证绘制节奏和依赖可控。
5. 在浏览器验证集体施工、当前区域完工后的分散待命、新区域招募，以及全页完工后的聚群跟随；操作原有链接和表单，并检查滚动、窗口缩放、销毁／重挂载、减少动态效果和触屏降级。只报告实际完成的验证。

## 必须保留的体验

- 群体运动具有速度差、追赶、转向和彼此避让；不能简化成固定间距的一串鼠标图标。
- 光标使用短小、圆润、无外伸长尾的凹口箭头，鲜亮协作配色、细白边和紧凑阴影。文本与十字工具保持纤细圆头，钢笔采用分体笔尖和空心圆孔；复用核心中的轮廓，避免退回尖硬的传统长尾箭头。
- **施工、待命和最终跟随是不同状态。** 页面还有未完成区域时，空闲光标应独立游走或离场，不能直接围着真实鼠标抱团。新区域出现后从边缘补充工人；只有全页任务完成，才进入最终光标群跟随。
- 工作光标有完整的接近、按下、施工、检查和撤离动作。任务按区域、距离与参与公平性分配；不要固定少数光标施工、其余永远作为跟随装饰。
- 光标的工作位置与正在显现的内容对应。文字逐步出现、矩形被拖出、SVG 沿实际路径描绘；不是全页统一淡入。
- 输入用有停顿的完整字符节奏，文本工具与实际插入光标分开显示。飞行方向、速度和短暂停顿有变化，但拖拽终点和文字定位必须准确。
- 多个任务同时推进，有依赖的元素按顺序出现。嵌套目标需明确父子依赖，避免父层仍隐藏时子层先施工。
- 覆盖层不拦截真实点击，不更改原有文案、语义结构和业务事件。不要关闭页面原本的键盘导航或表单校验。
- 默认尊重 `prefers-reduced-motion`，粗指针／触屏设备默认关闭效果，内容直接可用。不要为视觉效果让页面永久不可见。
- 不强制隐藏系统鼠标。页面失焦、重新布局、SPA 卸载之后，不留多余动画循环、监听器或遮罩。

## 边界与材料

本 skill 用于有源码或 DOM 修改权限的页面。第三方 URL、跨域 iframe、封闭 Shadow DOM 和原生应用不能仅凭一个调用自动改造。复杂组件可以选择 `reveal` 或 `data-swarm-ignore`，不必破坏其内部结构。

原站的独立场景模型包含辅助线吸附、复制组件等设计软件表演。本核心提取可迁移的群体运动和绘制机制，不承诺模拟所有编辑器操作。原站观察和实现差异见 [references/reference-study.md](references/reference-study.md)。

已完成的验证、复跑方法和浏览器覆盖范围见 [references/validation.md](references/validation.md)。
